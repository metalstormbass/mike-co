# Chainguard Security Scan Results

This directory contains vulnerability scan results for all container images in the RAG Knowledge Base application.

**All images use [Chainguard](https://www.chainguard.dev/) hardened base images** (`cgr.dev/mikeco.com/*`), which are distroless containers with minimal to zero CVEs.

Scans are automatically generated by the CI/CD pipeline using [Grype](https://github.com/anchore/grype).

> **Security Benefits**: All images use [Chainguard hardened base images](https://www.chainguard.dev/), which provide:
> - **Zero known CVEs** through daily automated patching
> - **Minimal attack surface** with distroless design (no shell, package manager, or unnecessary tools)
> - **SLSA Build Level 3** provenance for supply chain security
> - **Significantly reduced vulnerabilities** compared to standard base images (Debian, Ubuntu, Alpine)

## Update Frequency

Scan results are updated automatically on every push to `original` or `chainguard` branches and weekly via scheduled scans.
